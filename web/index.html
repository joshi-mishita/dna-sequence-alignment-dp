DNA Sequence Alignment Using Dynamic Programming

Two DNA sequences can differ by substitutions, insertions and deletions. The Needleman–Wunsch algorithm finds the best global alignment by solving every prefix pair once, storing the answers in a matrix, and building the full alignment from them. Run an alignment, then step through the matrix cell by cell.

Global alignment (Needleman–Wunsch) must account for every base of both sequences. Local alignment (Smith–Waterman) searches for the most similar region: cells never fall below 0, so a poor stretch can be dropped and a fresh alignment started. Both are computed independently with the same scoring.
